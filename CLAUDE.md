# Лига-Строй — сайт-визитка

## О проекте

Одностраничный статический сайт-визитка строительной компании «Лига-Строй».
Простой HTML/CSS/JS без сборщиков и фреймворков — открывается напрямую через
`index.html` или любой статический хостинг.

## Структура файлов

```
index.html      — вся разметка страницы (единственный HTML-файл)
css/style.css   — все стили (CSS-переменные в :root в начале файла)
js/script.js    — бургер-меню на мобильных, тень шапки при скролле, год в футере
README.md
```

## Технические решения

- Шрифты: Google Fonts — Montserrat (заголовки) + Manrope (текст).
- Иконки: Font Awesome 6 (Free) через CDN (`cdnjs.cloudflare.com`),
  используются классы `fa-solid` / `fa-brands` (whatsapp, telegram).
- Цветовая палитра — CSS-переменные в `css/style.css`:
  - `--color-navy*`, `--color-blue*`, `--color-gray*` — базовые оттенки серого/синего;
  - `--color-accent` (`#e08a2c`, тёплый оранжевый) — единственный акцентный
    цвет, используется для CTA-кнопок и точечных акцентов.
- Адаптивная вёрстка: брейкпоинты на 899px (переход на мобильное меню-бургер),
  720px и 520px (перестройка сеток услуг/преимуществ).
- Мобильное меню и три кнопки связи в шапке на мобильных скрываются под
  бургер (см. `.main-nav.is-open`, `.header-contacts.is-open` в CSS и
  логику в `js/script.js`).
- Телефон единый везде: `+7 985 423-74-67` → `tel:+79854237467` для звонка,
  `wa.me/79854237467` для WhatsApp, `t.me/+79854237467` для Telegram.
  При изменении номера нужно поправить его во всех трёх местах в `index.html`
  (шапка — 3 кнопки, hero-секция, секция «Контакты», футер).

## Разделы страницы (`index.html`, якоря)

- `#top` — шапка + hero-блок (заголовок, буллиты-цифры, 3 кнопки связи).
- `#services` — «Услуги», сетка из 9 карточек (все виды работ из ТЗ).
- `#about` — «О компании» (опыт, штат без субподряда, склад, частные/гос. заказчики).
- `#advantages` — «Преимущества» (3 карточки: склад, штатная команда, технологии).
- `#contacts` — «Контакты» (телефон крупно + 3 кнопки связи + регион работы).
